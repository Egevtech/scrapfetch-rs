# SCRAPFETCH-RS
Проект нагло спперт с [отседа](https://github.com/amodi444/scrapfetch)

# Установка
## Установка через Cargo
```
cargo install --git https://github.com/egevtech/scrapfetch-rs
```

## Доступен пакет в AUR
```
git clone https://aur.archlinux.org/scrapfetch-rs
cd scrapfetch-rs
makepkg -si
```

## Сборка RPM
```
cargo generate-rpm
```
